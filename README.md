# ip-local.com Connection Diagnostic

A simple, privacy-friendly connection diagnostic tool for users and IT support.

Official tool: https://ip-local.com/en/connection-diagnostic/

## What it does

The tool helps a user copy or download a basic connection report that can be sent to a technician, helpdesk or IT support team.

The diagnostic includes:

* Public IP address
* Browser
* Operating system / platform
* Language
* Time zone
* Screen size
* Window size
* User agent
* Page checked
* Date and time

It also explains that the local/private IP address cannot usually be detected automatically by the browser, and links to device-specific guides to find it manually.

## Why this exists

When someone has a network issue, support teams often need basic information before they can help.

Instead of asking the user to search through settings, copy technical values manually or send screenshots, ip-local.com provides a clean report that can be copied or downloaded in one click.

## Privacy

ip-local.com is designed to be simple and privacy-friendly.

* No advertising cookies
* No user accounts
* No login
* No form submission required
* No personal profile creation

The diagnostic is generated in the browser and copied or downloaded by the user.

Privacy and legal information: https://ip-local.com/en/privacy-terms/
