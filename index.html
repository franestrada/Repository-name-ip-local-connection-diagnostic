Tell the user to open this page, copy the diagnostic and paste it into the support ticket. It gives you the public IP, browser, device context and a clean timestamp in one block.

How to use it

  1. Open this page on the affected device.
  2. Wait until the public IP appears.
  3. Copy or download the diagnostic.
  4. Send it to your technician or support team.

Privacy note

Simple by design

The diagnostic is generated in your browser. To retrieve the public IP, this build first tries the site’s Cloudflare trace endpoint and otherwise calls api.ipify.org. It contains no advertising or analytics code and does not ask for your name, email, password or precise location.

Quick answers

Common questions

Does this show my local IP?

No. A normal browser usually cannot detect your local IP automatically. Use the device guides if you need the private address inside your network.

What is this useful for?

It is useful when a technician asks for basic connection data before troubleshooting a router, VPN, firewall, access or browser problem.

Can I share this safely?

Share it only with people or support teams you trust. A public IP and user agent are technical details, but they still describe your connection.
